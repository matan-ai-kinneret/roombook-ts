# ADR 0001 — אחסון בקבצי JSON

סטטוס: התקבל · תאריך: נובמבר 2026

## הקשר
roombook מתחיל ככלי שורת פקודה לשימוש בדלפק הספרייה ובסדנה. יש 8 חדרים ועשרות הזמנות ביום. אין צורך בגישה מקבילה ממספר מחשבים בשלב הזה, ואנחנו רוצים שכל סטודנט יוכל להריץ את הפרויקט בלי להתקין מסד נתונים.

## החלטה
הנתונים נשמרים בשני קבצים: `data/rooms.json` (קריאה בלבד) ו-`data/bookings.json`. כל הגישה עוברת דרך שכבת `store` (`JsonStore` / `MemoryStore`), כך שהחלפה למסד נתונים תשפיע רק על הקובץ הזה. הבדיקות משתמשות ב-`MemoryStore`.

## השלכות
- פשוט להתקנה ולדיבוג: אפשר לפתוח את הקובץ ולראות את המצב.
- אין נעילות: שני תהליכים שכותבים במקביל עלולים לדרוס זה את זה. מקובל בשלב הזה.
- `data/*.json` לא נערכים ידנית ולא על ידי סוכן — רק דרך ה-CLI או הבדיקות.
- כשנעבור לגישה מרובת משתמשים (API), נפתח ADR חדש למעבר ל-SQLite.
